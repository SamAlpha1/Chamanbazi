# Security Policy

Maintained by **SamAlpha1**.

## Reporting a vulnerability

Do not publish private keys, seed phrases, access tokens, passwords, or exploit details in public issues. Open a minimal issue without sensitive data and request a private contact path.

## Security principles

- Never commit secrets or credentials.
- Keep local secret files out of Git.
- Review workflow and dependency changes before merging.
- Treat automation tokens and repository permissions as security-sensitive.
